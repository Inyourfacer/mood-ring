1. Connect to GitHub

Each device needs an access token so it can save your (encrypted) check-ins to the repo.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → .
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Expiration: the longest option offered. Generate it and paste it here.

2. Passphrase

This passphrase encrypts everything. If you lose it, nobody can recover your data. Save it in your password manager. Use four or more random words, e.g. copper-violin-harbor-mitten.

Enter your passphrase once on this device. It stays remembered here.

Unlocked on this device.

3. Notification keys

Do this once, ideally on a computer.

Generates the key pair that lets your repo's reminder job send notifications to your devices.

Copy this private key now. It's shown only once and is never saved anywhere else.

  1. Open repo Settings → Secrets → Actions → New secret.
  2. Name: VAPID_PRIVATE_KEY. Value: paste the key. Click Add secret.

Keys exist. Make sure the VAPID_PRIVATE_KEY secret is set in repo secrets.

Lost the private key? Generate new keys, update the secret, then turn notifications on again on each device.
